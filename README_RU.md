# NEON RUN 3D

Мобильный 3D endless runner для Android. Игра офлайн, управление свайпами.

- Влево / вправо — смена дорожки
- Вверх — прыжок
- Вниз — подкат
- Собирай монеты и избегай препятствий

APK собирается через GitHub Actions: открой вкладку **Actions**, дождись завершения **Build Android APK**, затем скачай артефакт **NeonRun3D-APK**.
